# Orkid Bridge MCP Skill

Cross-chain bridge quotes and routing for EVM tokens via the Orkid solver
network — bridge USDC, WETH, and other tokens between Base, Ethereum,
Arbitrum, Polygon, and Robinhood Chain (4663). Non-custodial: the
depositor wallet signs.

This repo's `SKILL.md` is published to the
[Smithery Skills Registry](https://smithery.ai) as `jjcav84/orkid-bridge-mcp`.

- MCP endpoint: `https://orkidlabs.xyz/api/mcp`
- stdio bridge: `npx -y orkid-swap-mcp`
- Official MCP Registry: `xyz.orkidlabs/orkid-swap`
- Docs: https://docs.orkidlabs.xyz/docs/x402
